# Clawson

Your personal AI operating system — for **Windows** and **Mac** (Apple Silicon and Intel).

## Download

Get the latest version from **[Releases](https://github.com/IsaiahTGothan/clawson-releases/releases/latest)**:

| Computer | File |
|---|---|
| Windows 10/11 | `Clawson-Setup-<version>.exe` |
| Mac with Apple Silicon (M1 and later) | `Clawson-<version>-arm64.dmg` |
| Mac with Intel | `Clawson-<version>-x64.dmg` |

Not sure which Mac you have? Apple menu → **About This Mac** → "Chip: Apple M…" means Apple Silicon.

**Mac first launch:** Clawson isn't signed by Apple yet. Open it once, click **Done**, then go to **System Settings → Privacy & Security** and click **Open Anyway**.

## Updates

Once installed, Clawson keeps itself up to date: an **Update** button appears at the top of Settings whenever a new version is out.
